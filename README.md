# 青禾农场

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose -p pinru-jdk005-1113 up --build`，打开 http://localhost:18025 。

## 品质检验

作物与成品不再用星级表示，而是按糖度（°Bx）、水分（%）、纯净度（%）三项记录：

- 田间：每小时按实际天气与缺水情况累积三项数值，晴天提糖降水分、雨天抬水分、大风与缺水损伤纯净度，播种时的天气会一路影响成品。
- 谷仓：每批库存都挂一张检验证书，记录三项实测值与来源份额（哪块地、第几茬、多少份）。拆包出售或领料时，证书份额同步核减，拆出的部分另发一张可追溯的证书。
- 工坊：莓果酱按数量加权混料、熬煮失水 70%；玉米粉每份等权、失水 52%，各有独立的纯净度上限与下限。
- 订单：直接指定三项指标的检验区间；备货失败或交付不合格会写明具体是哪一项、实测多少、要求多少。
- 存档：旧版星级记录迁移为明确的默认区间（标注“未重新检验”），不会伪造测量值；重复备货或已过期的旧预留按真实剩余数量裁掉，对应的订单退回待备货。
